# Czech Bastard Lab website

A lightweight static website for the Czech Bastard Lab portfolio and enquiry-based shop.

## Files
- `index.html` — website structure and content
- `styles.css` — responsive black/gold industrial styling
- `script.js` — mobile navigation and product enquiry interactions

## Preview locally
Open `index.html` in a browser.

## Deploy with Cloudflare Pages
1. In Cloudflare, open **Workers & Pages** and create a Pages project.
2. Choose **Connect to Git** and authorize the GitHub account.
3. Select `woofer273-art/czech-bastard-lab`.
4. For a plain HTML/CSS/JS site, leave the build command blank and set the build output directory to `/` (or the root directory, as the UI specifies).
5. Deploy. New commits to `main` will trigger new deployments.

## Before launch
- Replace the CSS illustration placeholders with photos of actual finished projects.
- Confirm prices and availability before advertising products.
- Add privacy, delivery and returns information as appropriate.
- Domain idea: `czechbastardlab.co.uk` (availability not checked).
- Instagram: https://www.instagram.com/czech_bastard_lab/

No payment processing or stock management is enabled. The shop currently handles enquiries through Instagram.
